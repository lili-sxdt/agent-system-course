# Agent 系统课程 · 从零到能编写（v0.1 → v0.2）

> 一门教"完全不懂 → 能自己编写 DeepSeek Harness 同类 Agent 系统，并发布维护到 v0.2"的课程。

## 这是什么课

- **定位**：不同于纯文档教程，本课以"**亲手搭建一个 mini-harness**"为主线，把 Agent 系统的每个部件做出来。
- **语言**：通俗易懂 + 专业规范；每章用五件套落地——① 大白话引入（打比方）→ ② 最小可跑示例 → ③ 专业定义/规范 → ④ 动手练 → ⑤ 验收标准。
- **技术底座**：Node + TypeScript（与 DSH 同栈，概念一一对应，学完可直接映射到 DSH 源码）。

## 课程目标

走完第〇~第九部分，你能：
1. 理解 Agent 系统五要素与核心架构（上下文/模型/工具/循环/人设）。
2. 独立写出自己的 Skill / 工具 / 角色，并在系统里跑起来。
3. 搭出一个可运行的 v0.1 mini-harness。
4. 走完"发布 → 反馈 → 验证 → 维护 → 修改 → 再发布 v0.2"的完整生命周期。

## 标注约定

## 写作规范（填充/校对时遵守）

- 标题：侧栏用短名、页面 H1 用全名；跨部分引用**必须带部分号**（见 `docs/title-spec.md`）。
- 每章：五件套齐全，末尾有**验收清单 + 追问**。
- 涉及具体 API/包名处**标注版本**，遵循"以官方为准"。
- 密钥：**永不写进代码或仓库**，用环境变量注入。

## 质量门

- 内容经**独立审计**（全新上下文审计官，非自审），裁决 PASS / CONDITIONAL / FAIL。
- 审计维度：技术准确性 / 完整性 / 一致性 / 教学性 / 站点结构 / 合规诚信。
