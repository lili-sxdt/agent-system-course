# 附录 A · 术语对照表（大白话 ↔ 专业词）

> 全课出现过的术语，按"大白话 / 专业词 / 一句话解释 / 在哪章"整理。卡壳时回来查。

> **章号说明**：表中"章"列写作 `A-B` = **第 A 部分第 B 章**（例如 `0-3` = 第〇部分第3章，`1-1` = 第一部分第1章）。
