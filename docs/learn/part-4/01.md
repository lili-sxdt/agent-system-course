# 第1章 会话（Session）与持久化

> 你的裸 Agent 现在"聊完就忘"——关掉程序，之前的一切都没了。这一章让它**记住**：引入"会话"，并把它**存下来**。

---

## 1.1 会话是什么

**大白话**：**会话（Session）** = 一段连续的对话。就像微信里的一个"聊天窗口"——你在这个窗口里说的话，都归这一次会话管；开个新窗口，就是新会话。

**专业**：Session 是**一次交互上下文的载体**，包含消息历史、会话 ID、元数据（创建时间、标题、用哪个模型等）。它是"把上下文组织起来"的容器。

```ts
interface Session {
  id: string
  messages: Message[]     // 这段对话的全部消息
  createdAt: number
  title?: string
}
```

**关键**：会话把"上下文"从"内存里一个数组"升级成"一个可标识、可管理、可存储的对象"。

---

## 1.2 持久化：把会话存起来

**大白话**：光在内存里，一关就没了。要**写进磁盘**——下次打开还在。

**专业**：**持久化（Persistence）** 就是把会话写到存储介质。两种常见方式：

| 方式 | 特点 | 适合 |
|---|---|---|
| **JSONL** | 一行一条消息，追加写、简单 | 中小规模、要人类可读 |
| **数据库** | 可查询、并发好、结构化 | 大量会话、要检索 |

JSONL 示例（每行一条消息，追加即可）：

```jsonl
{"role":"user","content":"帮我读 config.json"}
{"role":"assistant","content":"好的"}
{"role":"tool","content":"{\"port\":8080}"}
```

**要点**：**追加写**（append）比"每次重写整个文件"更安全、更快——只加不改。

---

## 1.3 会话恢复

**大白话**：下次打开，把存的消息**读回来**，接着聊。

**专业**：**会话恢复** = 从存储加载历史消息，重建上下文，继续对话。注意点：

- **消息顺序**必须还原（顺序错=失忆）；
- **工具结果**也要存（否则恢复后模型不知道之前工具返回了啥）；
- **版本兼容**：存储格式可能升级，要能读旧格式（第9部分会讲迁移）。

```ts
// 示意：从 JSONL 恢复
const messages = (await fs.readFile('session.jsonl', 'utf8'))
  .split('\n').filter(Boolean).map(line => JSON.parse(line))
```
