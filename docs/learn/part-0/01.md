# 第1章 什么是大模型 Agent

> 本章是零门槛第一课：用大白话讲清"Agent 是什么、它和普通聊天机器人差在哪、为什么原来那套聊天不够用"。看完你就能对身边任何"AI Agent"产品有第一层判断力。

如果你只跟 ChatGPT 这类聊天机器人聊过天，你可能觉得 AI 就是"你问它答"。但这门课要讲的 Agent，是另一种东西——**它不只是回答你，而是帮你把事情做完。**

---

## 1.1 一个"会动手的执行者" {#sec-1}

**大白话**：聊天机器人是一张**只会说话的嘴**；Agent 是一个**会动手的执行者**。你给它一个任务，它不只是"说"给你听，而是**真的去做**——读文件、跑程序、查资料，然后把做好的结果交给你。

举个例子：

> 你对聊天机器人说："帮我把今天收集的那批数据整理成一份表格。"
> 它只能回你："抱歉，我无法访问你的文件，你可以……"

> 你换一个 Agent 说同样的话，它（背后有一套系统）会**真的找到你的数据文件 → 读取 → 分析 → 生成表格 → 交给你**。

**专业**：Agent 是一个以**大语言模型（LLM）为"大脑"**的系统，它能**感知环境、调用工具、决定下一步行动、并观察行动结果**，通过循环推进直至完成一个目标。它不是一个模型本身，而是"模型 + 一圈让它能行动的外围"。

---

## 1.2 大模型的能力边界 {#sec-2}

要理解 Agent，先得知道**模型的边界**——因为 Agent 就是为"补足这些边界"而生的。

**模型擅长**：理解语言、推理、总结、翻译、写代码片段、回答问题。
**模型不擅长**：
- **精确计算**（容易算错，尤其多位运算）；
- **访问实时/外部数据**（它不知道现在几点、天气怎样、你最近的报价）；
- **直接操作系统和文件**（它不能替你打开文件、改配置、跑命令）；
- **长期准确记忆**（上下文一长，它会"忘掉"或记混早期细节）。

**正因如此**，模型才需要：
- **工具（手）**——替它做模型自己做不到的事；
- **上下文（记忆）**——替它留住"要知道的事"。

这两样，正是后面几章的核心。

---

## 1.3 为什么单靠"聊天"搞不定真实任务 {#sec-3}

很多真实任务**不是一句回复能解决的**，它们是"分几步、用几个工具、前后有依赖"的过程。比如"把这个文件夹里的报告都改成统一的格式"——要列目录、读文件、改内容、再写回去，前后好几步，还得看每步结果决定下一步。

聊天机器人"一问一答"一次就结束了，撑不起这种多步过程。而 Agent 用一个**循环**把"想→做→看→再想"反复转起来，直到做完。**循环**正是 Agent 和聊天机器人的分水岭，也是本课程要亲手搭的核心。

**一句话**：聊天机器人是"一问一答"，Agent 是"接任务 → 分步执行 → 交付结果"。差别就在"**会不会动手 + 会不会一环一环推进**"。

> **体感一下**（先看懂，不急着做）：下面是一次真实的 Agent 循环。你给它"读一下 README 的标题"，它不会只回一句话，而是**自己决定先读文件、再回答**：
>
> ```
> [step 0] 想：需要文件内容 → 调用 read_file("README.md")
> [step 1] 看结果：读到标题文字
> [step 2] 想：够了 → 回答 "项目名是 Mini-Harness"
> ```
>
> 注意那行 `read_file`——这就是"模型自己开口要工具"的瞬间，也是它和聊天机器人的真正分水岭。后面 [实践线第1部分](/learn/practice/part-1/01) 会亲手做出这条链。
