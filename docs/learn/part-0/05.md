# 第5章 环境准备

> 准备动手了。这一章教你搭好开发环境，并跑通一个"最小的 Agent 程序"——**hello-agent**。这是你这门课的第一块"能跑的砖"。

我们用的技术栈：**Node.js + TypeScript**（和 DSH 同栈，学完能直接对接 DSH 源码）。

---

## 5.1 安装 Node.js 与 npm {#sec-1}

**大白话**：Node.js 是个"让 JavaScript 能跑在电脑上"的运行时；npm 是它的"软件超市"，用来装第三方库。装好这俩，就能跑 JS/TS 项目。

**步骤**：
1. 到官网下载 LTS 版本（[nodejs.org](https://nodejs.org/)），按提示安装。
2. 装完打开终端（Windows 用 PowerShell / CMD），验证：

```bash
node -v     # 显示版本号，如 v22.x
npm -v      # 显示版本号，如 10.x
```

**专业**：Node.js 是 V8 引擎驱动的 JavaScript 运行时，提供文件系统、网络、进程等能力（我们后面要用）。npm（Node Package Manager）负责依赖安装与版本管理。

## 5.2 初始化一个 TypeScript 项目 {#sec-2}

**大白话**：TypeScript 是"带类型的 JavaScript"，能提前帮你发现错误。我们现在建一个能写能跑的 TS 项目。

这一步在终端里执行（在你想放项目的文件夹下）：

```bash
mkdir my-agent && cd my-agent
npm init -y                      # 生成 package.json
npm install -D typescript @types/node
npx tsc --init                    # 生成 tsconfig.json
```

**专业**：
- `npm init -y` 生成 `package.json`（项目清单）。
- `npm install -D` 装开发依赖：`typescript`（TS 编译器）、`@types/node`（Node 的类型声明）。
- `npx tsc --init` 生成 `tsconfig.json`（TS 编译配置）。

## 5.3 跑通 hello-agent（最小 Agent 程序） {#sec-3}

**大白话**：我们不先搞复杂，先让程序"会调用一次大模型"——这就是最小的 Agent 雏形：给模型一句话，让它回一句。

写一个 `hello-agent.ts`（示意，用 OpenAI 兼容接口；**以你实际模型/服务为准**）：

```ts
// hello-agent.ts —— 最小可用：发一条消息，取回回复
// Node 18+ 自带全局 fetch，无需额外安装（旧版本可改用 node-fetch）

const MODEL = 'deepseek-chat'        // 换成你实际使用的模型名
const API = 'https://api.deepseek.com/chat/completions'   // 换成你实际服务地址
const KEY = process.env.LLM_API_KEY! // 密钥放环境变量，别硬编码！见下方提醒

async function main() {
  const res = await fetch(API, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${KEY}`,
    },
    body: JSON.stringify({
      model: MODEL,
      messages: [
        { role: 'system', content: '你是一个简洁的助手。' },
        { role: 'user', content: '用一句话介绍你自己。' },
      ],
    }),
  })
  const data = await res.json()
  console.log(data.choices?.[0]?.message?.content ?? data)
}

main()
```

运行：

```bash
# 先设置密钥（Windows/PowerShell）
$env:LLM_API_KEY = "你的密钥"
# 再运行
npx tsx hello-agent.ts
```

> **重要提醒（安全）**：**密钥（API Key）放环境变量，别写死在代码里，更不能提交到 GitHub。** 后面第4/7部分会专门讲密钥与安全管理。

**专业**：这条链路其实已经含了 Agent 的"第一步"——**把 context（system + user 消息）交给模型**。真正的 Agent 会在后面加上"工具 + 循环"（第1部分第2~5章）。

**动手练**：把 `content` 改成一个需要"查资料/算数"的请求，看看模型是直接回答，还是告诉你"它做不到"——这正好验证第1章讲的"能力边界"。
