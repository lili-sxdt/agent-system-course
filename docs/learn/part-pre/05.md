# 预备 5 · TypeScript 类型

> TS 让"长什么样"提前写清楚，IDE 帮你查错。这章是看懂课程类型写法的关键。

## 1 类型标注 {#sec-1}

```ts
const name: string = 'Alice'
function add(a: number, b: number): number {
  return a + b
}
```

> 写法：`变量/参数: 类型`，函数后 `: 返回类型`。

## 2 interface（最常用） {#sec-2}

```ts
interface Message {
  role: 'system' | 'user' | 'assistant'
  content?: string            // ? = 可选
}
const m: Message = { role: 'user', content: 'hi' }
```

> 像 Python 的 `TypedDict`/dataclass；`?` 表示可有可无；`|` 联合类型（几个之一）。

## 3 泛型 `<T>` {#sec-3}

```ts
function first<T>(arr: T[]): T {
  return arr[0]
}
const n: number = first([1, 2])   // T 推断为 number
```

> 像 `list[int]`；`Promise<{ ok: boolean }>` 就是"返回某对象的 Promise"。

## 4 类型断言 as {#sec-4}

```ts
const data = JSON.parse(text) as { ok: boolean; error?: string }
```

> 当 TS 猜不准、但你知道时，用 `as` 告诉它。

## 5 组合看课程代码 {#sec-5}

```ts
const messages: Message[] = [ ... ]
const r = await chat(messages) as { content: string }
```

> 看懂 `Message[]`（Message 数组）、`as {...}`（断言）、`Promise<{...}>`，课程类型就通了。

> **接下来会用到**：这里几乎就是第1~3部分代码的"形状"——`messages: Message[]`（对话数组）、`Promise<{ ok: boolean }>`（工具返回值）、`as {...}`（解析模型返回）。看懂这些，后面读代码不卡壳。

## 验收 {#sec-6}
- [ ] 会写 `const x: type`、函数返回类型；
- [ ] 会用 `interface` + `?` 可选 + `|` 联合；
- [ ] 知道 `<T>` 泛型大致用途；
- [ ] 会用 `as` 断言。

**追问**：`interface Person { name: string; age?: number }`，`age` 能不能不给？（提示：`?` 可选，可以不给）
