# 预备 1 · 变量与类型

> 先弄清"变量是啥、能存什么"。用 `const/let` 声明变量，类型有 `string/number/boolean` 等。

## 1 声明变量：const / let {#sec-1}

```ts
const name = 'Alice'   // 常量：声明后不能改（默认用它）
let count = 0          // 变量：可以改
count = count + 1      // 改值
```

> **对照**：Python 直接 `x = 1`；JS 要写 `const`/`let`。**默认用 `const`**，需要改才用 `let`。

## 2 基础类型 {#sec-2}

| JS/TS 类型 | 存什么 | 例 | Python | R |
|---|---|---|---|---|
| `string` | 字符串 | `'hi'` | `str` | `character` |
| `number` | 数字 | `42`、`3.14` | `int`/`float` | `numeric` |
| `boolean` | 真/假 | `true`、`false` | `bool` | `TRUE/FALSE` |
| `null` | 显式空 | `null` | `None` | `NULL` |
| `undefined` | 未定义 | `undefined` | — | — |

```ts
const a = 42        // number
const s = 'hello'   // string
const b = true      // boolean
const n = null      // null（明确"没有值"）
const u = undefined // undefined（没赋值）
```

## 3 类型标注（TS 增强） {#sec-3}

> TS 能写 `: type`，让 IDE 提前发现类型错。

```ts
const age: number = 30
const name: string = 'Alice'
let ok: boolean = true
```

> 写成 `number/string/boolean`，不是 `int/str/bool`。

## 4 运算示例 {#sec-4}

```ts
const x = 5
const y = 2
console.log(x + y)     // 7
console.log(x - y)     // 3
console.log(x * y)     // 10
console.log(x / y)     // 2.5
console.log(x % y)     // 1（取模）
console.log(x > y)     // true
console.log(x === 5)   // true（严格相等）
console.log(x === '5') // false（数字 5 ≠ 字符串 '5'）
```

> **要点**：用 `===` 严格相等；`x / y` 是浮点（不是整除）。

## 5 模板字符串 {#sec-5}

```ts
const name = 'Alice'
const age = 30
console.log(`${name} is ${age}`)   // Alice is 30
```

> **对照**：Python `f"{name} is {age}"`；R 用 `paste`/`glue`。JS 用**反引号 + `${}`**。

## 验收 {#sec-6}
- [ ] 会 `const`/`let` 声明，默认 `const`；
- [ ] 认 `string / number / boolean / null / undefined`；
- [ ] 会 `+ - * / %`、`===`、`>`、`&& || !`；
- [ ] 会用模板字符串。

**追问**：`3 === '3'` 结果是 `true` 还是 `false`？为什么？（提示：`===` 要求类型也相等，数字 ≠ 字符串）
