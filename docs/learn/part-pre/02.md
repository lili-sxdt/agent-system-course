# 预备 2 · 数组与对象

> 数组 = 一列数据；对象 = 一组"键:值"（像词典、像数据框的一行）。这两个是后面所有代码的容器。

## 1 数组 array {#sec-1}

```ts
const nums = [1, 2, 3]
nums.push(4)                       // 追加 → [1,2,3,4]
const d = nums.map(n => n * 2)     // 每个×2 → [2,4,6,8]
const evens = nums.filter(n => n % 2 === 0)  // 偶数 → [2,4]
const total = nums.reduce((a, b) => a + b, 0) // 求和 → 10
console.log(nums.length)           // 长度 → 4
console.log(nums[0])               // 下标取 → 1
```

> **对照**：`push` 类似 Python `append`；`map/filter` 类似列表推导式；`reduce` 类似 `sum`。R 类似 `sapply`/`Filter`。

## 2 对象 object {#sec-2}

```ts
const user = { name: 'Alice', age: 30 }
console.log(user.name)     // Alice（点访问）
user.age = 31              // 改值
console.log(user.age)      // 31
```

> **对照**：Python 字典 `user['name']`；JS 用 `.` 或 `['name']`。R 的 list 用 `$`。

## 3 解构（从对象/数组取多个） {#sec-3}

```ts
const user = { name: 'Alice', age: 30 }
const { name, age } = user        // 一次取出 → name='Alice', age=30

const [first, second] = [10, 20]  // 数组解构 → first=10, second=20
```

> 课程里常见 `async function f({ path })`——就是解构取参数。

## 4 展开 spread {#sec-4}

```ts
const a = [1, 2]
const b = [...a, 3]           // → [1,2,3]
const o = { name: 'Alice' }
const o2 = { ...o, age: 30 }  // 合并 → { name:'Alice', age:30 }
```

> **要点**：`...` 展开，常用来拷贝/合并。

## 5 把一个对象列表里的信息取出来（很常用） {#sec-5}

```ts
const files = [{ name: 'a.md' }, { name: 'b.md' }]
const names = files.map(f => f.name)   // ['a.md','b.md']
```

> 这就是"取出一列的某个字段"——`files.map(f => f.name)`。
