# 预备 4 · 类与对象

> 类是"模板"，对象是"模板造出来的实例"。课程里一些抽象（如 `ToolDef`、`Session`）用 interface 描述结构，少数用类。

## 1 一个简单类 {#sec-1}

```ts
class Dog {
  name: string               // 属性
  constructor(name: string) {  // 构造器：创建实例时调用
    this.name = name
  }
  bark() {                    // 方法
    return `${this.name} says woof`
  }
}

const d = new Dog('Rex')
console.log(d.bark())   // Rex says woof
```

> **对照**：`class Dog:` + `__init__` → JS 的 `constructor`；`self.name` → `this.name`。

## 2 继承（简） {#sec-2}

```ts
class Puppy extends Dog {
  bark() {
    return `${this.name} says yip`   // 覆盖父类方法
  }
}
```

## 3 你会遇到的样子（课程里多是这样） {#sec-3}

```ts
interface ToolDef {        // 定义"长什么样"（见预备5）
  name: string
  handler(args: any): Promise<{ ok: boolean }>
}

const t: ToolDef = {
  name: 'read_file',
  async handler(args) { return { ok: true } },
}
```

> 其实课程里**大多是 `interface` + 对象字面量**，不常写 `class`。所以 class 了解即可，interface 更重要。

> **接下来会用到**：`interface`（加对象字面量）就是课程里定义"长什么样"的主力——`ToolDef`、`Session`、`Message`、`SkillDef` 基本都是 interface；你在第2/3部分写工具、技能、人设时就在定义这些 interface。
