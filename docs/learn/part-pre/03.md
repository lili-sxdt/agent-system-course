# 预备 3 · 函数与控制流

> 函数是"一段可复用的逻辑"，控制流是"判断和循环"。写 agent 全靠 `async function` + `if/for`。

## 1 函数：普通 + 箭头 {#sec-1}

```ts
function add(a, b) {         // 普通函数
  return a + b
}
const mul = (a, b) => a * b   // 箭头函数（最常用）

console.log(add(2, 3))   // 5
console.log(mul(2, 3))   // 6
```

> **对照**：`def add(a,b): return a+b` → `function add(a,b){ return a+b }`；箭头 `(a,b)=>a*b` 类似 `lambda a,b: a*b`。

## 2 箭头函数里省略 return（一条语句） {#sec-2}

```ts
const double = x => x * 2   // 单表达式省略 return，等同 x => { return x*2 }
```

## 3 if / else {#sec-3}

```ts
const score = 75
if (score >= 60) {
  console.log('pass')
} else {
  console.log('fail')
}
```

> **对照**：`if score >= 60:` → `if (score >= 60) {`；用花括号，不用冒号。

## 4 for .. of（遍历数组） {#sec-4}

```ts
const nums = [1, 2, 3]
for (const n of nums) {
  console.log(n)      // 1 2 3
}
```

> **对照**：`for n in nums:` → `for (const n of nums) {`。R 用 `for (n in ...)`。

## 5 结合：一个函数 + 判断 + 循环 {#sec-5}

```ts
function countEven(list: number[]) {
  let c = 0
  for (const n of list) {
    if (n % 2 === 0) c++
  }
  return c
}
console.log(countEven([1, 2, 3, 4]))   // 2
```
