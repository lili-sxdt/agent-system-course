# 预备 6 · Node 与异步

> Node 让 JS/TS 在电脑上跑；异步（`async/await`）处理"等文件/等网络"。课程几乎全靠它。

## 1 模块 import / export {#sec-1}

```ts
import fs from 'node:fs/promises'     // 导入内置模块
import path from 'node:path'
export function double(x: number) {   // 导出
  return x * 2
}
```

> **对照**：`import os` → `import ... from 'node:...'`；Node 内置模块加 `node:` 前缀。

## 2 async / await {#sec-2}

```ts
import fs from 'node:fs/promises'

async function main() {
  const text = await fs.readFile('a.txt', 'utf8')  // 等读完再继续
  console.log(text)
}
main()
```

> **对照**：`async def` + `await` → `async function` + `await`。JS 是单线程事件循环，但用法几乎无感。

## 3 常用能力 {#sec-3}

```ts
import fs from 'node:fs/promises'
import path from 'node:path'
import os from 'node:os'

const text = await fs.readFile('config.json', 'utf8')   // 读文件
const p = path.join(os.tmpdir(), 'x')                  // 拼路径
const key = process.env.LLM_API_KEY                    // 读环境变量
const data = JSON.parse(text)                          // JSON 字符串→对象
```

> **安全**：密钥用 `process.env` 读，**绝不写死在代码、绝不提交 Git**。

## 4 一个最小可跑例子 {#sec-4}

```ts
import fs from 'node:fs/promises'

async function main() {
  const key = process.env.LLM_API_KEY
  const cfg = JSON.parse(await fs.readFile('config.json', 'utf8'))
  console.log('key set:', Boolean(key), '| port:', cfg.port)
}
main()
```
> 跑：`tsx hello.ts`。这就是后面 hello-agent 的骨架。
