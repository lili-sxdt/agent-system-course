# 预备 0 · 环境搭建

> 先把"能跑"这一步打通。这章装好 Node、建一个 TS 项目、跑通第一行 `console.log`。做完这章，你就有了后面所有练习的环境。

> **预备 → 主线 / 实践线**：这是整门课的**前置区**——先补齐 JS/TS/Node 基础（预备 0~6），再进 **[主线 第1部分（地基）](/learn/part-1/01)** 学概念，或直接去 **[实践线 第1部分](/learn/practice/part-1/01)** 动手。语法不够用随时回这查。

## 1 装 Node {#sec-1}

> JS/TS 靠 **Node** 在电脑上运行（就像 Python 靠解释器）。装好 Node 就自带 `npm`（装库的工具）。

1. 到 <https://nodejs.org/> 下载 **LTS** 版本，按提示安装；
2. 打开终端（Windows 用 PowerShell / CMD），验证：
```bash
node -v     # 应显示 v22.x 之类
npm -v      # 应显示 10.x 之类
```
> 对照：`python --version` ↔ `node -v`；`pip` ↔ `npm`。

## 2 建一个 TS 项目 {#sec-2}

> 在你想放项目的文件夹里：

```bash
mkdir my-agent && cd my-agent
npm init -y                      # 生成 package.json（项目清单）
npm install -D typescript @types/node   # 装 TS 与 Node 类型
npx tsc --init                   # 生成 tsconfig.json（TS 配置）
```

说明：
- `npm init -y` 类似 `python` 的"建项目"；`package.json` 类似 `requirements.txt` + 项目元信息；
- `npm install -D` 装"开发依赖"（写代码时用），类似 `pip install`。

## 3 跑第一个 .ts {#sec-3}

> 直接跑 TS，用 **tsx**（Node 不能直接跑 TS，需转译器）。

```bash
npm install -D tsx
tsx hello.ts        # 用下面的 hello.ts
```

> **对照**：跑 `py x.py` → 跑 `tsx x.ts`。

一个最小的 `hello.ts`：
```ts
const a = 2
const b = 3
console.log(a + b)                 // 输出: 5
console.log("hello, " + (1 + 2))   // 输出: hello, 3
```

> **注意**：JS 里 `字符串 + 数字` 是**拼接**（`"hello, " + 1 + 2` → `"hello, 12"`）；要算数请加括号写 `+ (1 + 2)`。

## 4 常用运算（先会这些） {#sec-4}

| 运算 | JS | 例 | 结果 |
|---|---|---|---|
| 加/减/乘/除 | `+ - * /` | `7 / 2` | `3.5` |
| 取模 | `%` | `7 % 2` | `1` |
| 相等/不等 | `===` `!==` | `2 === 2` | `true` |
| 大于/小于 | `>` `<` | `3 > 2` | `true` |
| 逻辑与/或/非 | `&&` `\|\|` `!` | `true && false` | `false` |

> **要点**：JS 用 `===`（严格相等）而不是 `==`；逻辑用 `&&`（和）、`\|\|`（或）、`!`（非）——和 Python 的 `and/or/not`、R 的 `&&/||/!` 对应，只是符号不同。

## 5 读文件（后面经常用） {#sec-5}

```ts
import fs from 'node:fs/promises'

const text = await fs.readFile('hello.ts', 'utf8')
console.log(text.length)   // 字符数
```

> `import ... from 'node:...'` 是导入内置模块；`await` 等读完再继续（见预备 6）。

> **接下来会用到**：这套「环境 + 跑 TS + 读文件」就是你后面所有练习的底座——实践线第1部分要自己写「读文件工具」，第4部分用 `fs` 做「会话落盘」，都会反复回来用这里的写法。
