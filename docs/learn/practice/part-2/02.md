# 例2 · 容器与注册思维

> 目标：学会"**向容器登记**"，而不是自己到处 `new`。理解 `ctx.plugin / tool / skill / on`。

## L1 用容器装插件 {#sec-1}

```ts
import { Context } from '@deepseek-ai/cordis'

const app = new Context()
app.plugin(myPlugin)          // 装一个插件
app.plugin(myPlugin, { enabled: true })   // 带配置
```

> 你只负责"登记"；容器负责按生命周期调用、传递配置。

## L2 注册能力：tool / skill / on {#sec-2}

```ts
export function myPlugin(ctx: Context) {
  ctx.tool(readFileTool)      // 注册工具：Agent 从此能调用它
  ctx.skill(mySkill)          // 注册技能：需要时被加载
  ctx.on('ready', () => console.log('ready'))   // 订阅事件
  ctx.on('dispose', () => console.log('cleaned'))
}
```

> **关键**：注册后，系统在组装时把工具/技能**自动收集**到"可用列表"，交给模型。**你只登记，收集分发由容器做。**

## L3 事件驱动解耦 {#sec-3}

```ts
// A 发事件
ctx.emit('data:ready', someData)

// B 监听（在另一个插件里）
ctx.on('data:ready', (data) => console.log('got', data))
```

> **解耦**：A 不用直接调用 B，只要 A 发事件、B 监听即可。

## 变体练习（举一反三） {#sec-4}

1. **写一个"计数插件"**：加载时把某工具注册进去，`dispose` 时打印"共用了多少次"。
2. **用事件解耦**：插件 A 在 `ready` 时 `emit('app:started')`，插件 B 监听它打印日志。

## 通用套路：注册思维 {#sec-5}

**别自己 new，向容器登记。** 工具/技能/事件都通过 `ctx.*` 注册，容器负责收集、分发、生命周期。
