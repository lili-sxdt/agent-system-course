# 例1 · 一个最小插件（能装能卸）

> 目标：理解"插件 = 自包含 + 统一接口 + 能装能卸"。把一个功能包成一个插件。

## L1 最小插件（骨架） {#sec-1}

```ts
import type { Context } from '@deepseek-ai/cordis'

export function myPlugin(ctx: Context) {
  ctx.on('ready', () => {
    console.log('my plugin is ready')
  })
}
```

> 一个插件 = 一个接收 `ctx` 的函数。`ctx.on('ready', ...)` 表示"系统就绪时做点事"。

## L2 现实中：能装能卸 + 清理 {#sec-2}

```ts
export function myPlugin(ctx: Context) {
  const timer = setInterval(() => { /* 干点定时活 */ }, 1000)

  ctx.on('dispose', () => {          // 卸载时清理
    clearInterval(timer)
    console.log('my plugin cleaned up')
  })
}
```

> **要点**：卸载时一定要**清理资源**（定时器/连接/监听），否则反复装卸会漏资源。

## L3 完整：一个"读文件插件" {#sec-3}

```ts
import { readFileTool } from './tools/read-file'

export function fileToolsPlugin(ctx: Context) {
  ctx.tool(readFileTool)     // 把工具挂进系统
  ctx.on('ready', () => ctx.something = true)
  ctx.on('dispose', () => console.log('fileTools plugin unmounted'))
}
```

## 变体练习（举一反三） {#sec-4}

1. **写一个"日志插件"**：`loggerPlugin`，`ready` 时启动一个定时器记录心跳，`dispose` 时清理。
2. **给插件加配置**：让它读一个配置项（见 例3）。

## 通用套路：插件 = 能装能卸 {#sec-5}

**一个能力 = 一个插件**；插件遵循统一接口被加载、能卸、干净地卸。改一个插件不影响其它插件。
