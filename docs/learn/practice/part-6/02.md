# 例2 · WebSocket 流式 + 前端展示

> 目标：让 Agent 的**流式输出**（一字一字冒）实时推给前端，并展示轨迹。

<!-- 双向导航: 回主线 -->
> 📚 **先用主线打底**：这一练对应 **[主线 第6部分](/learn/part-6/01)**——建议先读主线概念，再动手做。

## L1 WebSocket：实时推送 {#sec-1}

```ts
// 先 npm i ws   （WebSocket 是第三方包，需安装）
import { WebSocketServer } from 'ws'

const wss = new WebSocketServer({ port: 3081 })
wss.on('connection', (ws) => {
  ws.send(JSON.stringify({ type: 'hello' }))
  // 推送一行模型输出
  ws.send(JSON.stringify({ type: 'token', content: '你' }))
})
```

> **WebSocket = 一直开着的双向通道**，服务端可主动推送（流式输出、工具进度）；HTTP 一问一答只能做一次性请求。

## L2 一个小前端：消息流 + 轨迹 {#sec-2}

> 界面要点：**先能聊，再好看**；**轨迹默认折叠、需要时展开**（调试 + 建立信任）。

```html
<pre id="trajectory" hidden></pre>
<ul id="messages"></ul>
<input id="input" />
<button id="send">发送</button>

<script>
  const ws = new WebSocket('ws://127.0.0.1:3081')
  const input = document.getElementById('input')
  const traj = document.getElementById('trajectory')

  function show(m) { document.getElementById('messages').innerHTML += `<li>${m}</li>` }
  function send() {
    ws.send(JSON.stringify({ type: 'user', content: input.value }))
    input.value = ''
  }
  document.getElementById('send').addEventListener('click', send)
  input.addEventListener('keydown', (e) => { if (e.key === 'Enter') send() })

  ws.onmessage = (e) => {
    const d = JSON.parse(e.data)
    if (d.type === 'token') show(d.content)          // 流式
    else if (d.type === 'trace') traj.textContent += '\n' + d.content  // 轨迹，默认隐藏
  }
</script>
```

> **轨迹可视化**：把工具调用折叠成"卡片"（可展开看参数/结果），按顺序展示。

## 变体练习（举一反三） {#sec-4}

1. **把流式渲染到前端**：模型一个字一个字出来时，前端追加。
2. **折叠轨迹**：默认收起，点开显示工具调用与结果。

## 通用套路：流式用 WS，展示靠轨迹 {#sec-5}

**流式输出**用 WebSocket（可推送）；简单一次性请求用 HTTP 就行，别过度设计。**默认折叠、需要展开**，既不过度干扰又能随时查证。
