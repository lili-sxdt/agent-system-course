# 例2 · 工作区与路径安全

> 目标：给 Agent 划一个"安全办公室"，并挡住想溜出去的路径（`../../`）。

## L1 定义工作区 + 越界校验 {#sec-1}

```ts
import path from 'node:path'

const WORKSPACE = process.env.DSH_PROJECT_DIR ?? process.cwd()

function safePath(workspace: string, userPath: string) {
  const abs = path.resolve(workspace, userPath)   // 解析成绝对路径
  const rel = path.relative(workspace, abs)        // 相对工作区
  if (rel.startsWith('..') || path.isAbsolute(rel)) {
    throw new Error('path out of bounds, access denied')
  }
  return abs
}

console.log(safePath(WORKSPACE, 'data/a.csv'))       // OK
// safePath(WORKSPACE, '../../Windows')              // 越界 → 抛错
```

> **要点**：用 `path.resolve` + `path.relative` 判断，**别用字符串拼接**。

## L2 工具里用安全路径 + 兜错 {#sec-2}

```ts
import path from 'node:path'

export const readFileTool = defineTool({
  name: 'read_file',
  description: '读取工作区内文件内容。',
  parameters: { type: 'object', properties: { path: { type: 'string' } }, required: ['path'] },
  async handler({ path: userPath }) {
    const workspace = process.env.DSH_PROJECT_DIR ?? '.'
    try {
      const abs = safePath(workspace, userPath)         // 先校验
      const fs = await import('fs/promises')
      return { ok: true, content: await fs.readFile(abs, 'utf8') }
    } catch (e: any) {
      return { ok: false, error: e.message }            // 越界或失败都不崩
    }
  },
})
```

## L3 设计几个安全文件工具 {#sec-3}

| 工具 | 作用 | 注意 |
|---|---|---|
| `read_file` | 读 | 大文件分页/截断 |
| `write_file` | 写 | **原子写**（临时文件+替换） |
| `list_files` | 列目录 | 限深度、跳过大目录 |
| `search` | 搜内容 | 限范围 |
| `edit` | 定点替换 | 精确匹配 |

## 变体练习（举一反三） {#sec-4}

1. **写一个 `write_file`**：同样先 `safePath`，用**原子写**（先写 `x.tmp` 再 rename）。
2. **列目录**：`list_files` 里对每个文件先校验在工作区内，越界跳过。

## 通用套路：先定工作区，再谈文件 {#sec-5}

**工作区 = 活动范围 + 安全边界**。文件操作先 `safePath` 校验，写入要**原子**、大文件要**截断**。越界**直接拒绝**，不要"尽力而为"。
