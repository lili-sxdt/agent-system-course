# 例1 · 写一个技能（SKILL.md）

> 目标：写一份能被系统加载、按需使用的"说明书"——技能。关键是 `whenToUse`。

<!-- 双向导航: 回主线 -->
> 📚 **先用主线打底**：这一练对应 **[主线 第3部分](/learn/part-3/01)**——建议先读主线概念，再动手做。

## L1 一个最小 SKILL.md {#sec-1}

```md
---
name: report-writing
description: 把研究结果写成规范的 IMRaD 论文结构。
whenToUse: 用户需要写论文、报告、摘要，或要求结构化写作时。
---

## 步骤
1. 确认研究对象与目标期刊。
2. 按 IMRaD 搭骨架：引言 / 方法 / 结果 / 讨论。
3. 每个结论附证据（数据、DOI）。
```

> **frontmatter 三要素**：`name`（唯一标识）· `description`（一句话说明）· `whenToUse`（何时加载，**最关键**）。

## L2 现实中：写清"何时用" {#sec-2}

> `whenToUse` 写太窄，用不上；写太宽，乱加载。要写"**什么场景该用**"。

```md
---
name: data-clean
description: 清洗实验数据（去缺失、统一单位、去异常）。
whenToUse: 用户给了一堆原始数据、要求整理成可分析表格时。
---

## 步骤
1. 先看数据字段与缺失情况。
2. 去缺失：删或插补（注明方法）。
3. 统一单位、去异常（> 3σ 标出）。
```

## L3 完整：正文按"清楚/可执行/可验证" {#sec-3}

```md
## 步骤
1. 读取 `data/*.csv`。
2. 检查 `head()` 与缺失率。
3. 缺失率 < 5% 删行；> 5% 用中位数插补。
4. 输出 `data_clean.csv`。

## 验收
- [ ] 无缺失
- [ ] 单位统一
- [ ] 异常已标注
```

## 变体练习（举一反三） {#sec-4}

为你熟悉的场景写一个 `SKILL.md`：
1. **统计作图**：帮你把数据画成"规范的科研图"。
2. **写周报**：把本周工作整理成固定模板。
要求：frontmatter（name/description/whenToUse）+ 步骤 + 验收。

## 通用套路：技能 = 按需加载的说明书 {#sec-5}

**技能不是提示词**，是可复用、可版本管理、按 `whenToUse` 加载的能力包。`whenToUse` 写得清楚，模型才会在对的时机用上它。
