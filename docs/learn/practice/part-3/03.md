# 例3 · 写一个人设并理解三者协作

> 目标：写一个 persona / preset，并理解"技能 / 工具 / 人设"怎么配合——模型该用哪个。

## L1 一个最小 persona {#sec-1}

```md
你是"数据管家"，一名严谨的数据分析助手。

## 职责
把用户给的数据整理成可分析的表格，并给出结论。

## 准则
- 先看数据、再下结论；不臆测
- 每个结论附证据（哪张表、哪个统计量）

## 输出风格
先给结论一句话，再给依据。
```

> 人设（persona）注入 **system**，决定身份/语气/边界。

## L2 完整：一个 preset（人设 + 模型 + 工具） {#sec-2}

```md
---
name: data-analyst
description: 严谨的数据分析助手
model: deepseek-chat
tools: [read_file, list_files, run_python]
---

你是"数据管家"，一名严谨的数据分析助手。

## 职责
把用户给的数据整理成可分析的表格，并给出结论。

## 准则
- 先看数据、再下结论；不臆测
- 拿不准就说明不确定，并给出验证方法
```

> preset = **一份配置**（人设 + 模型 + 工具 + 默认参数），一处配置、到处复用。

## L3 三者协作：模型怎么选 {#sec-3}

| 你写什么 | 帮模型解决 | 配合点 |
|---|---|---|
| 工具描述 | 这步该不该动手、用哪个 | 写清"何时用" |
| 技能说明 | 这类任务怎么做才对 | 写清"何时加载 + 步骤" |
| 人设准则 | 我该守什么底线 | 写清"不许做什么" |

**例子**：用户说"把这批数据整理成表并分析"。
- **人设**（数据管家）说：先看数据再下结论；
- **技能**（数据分析规范）说：按什么流程；
- **工具**（read_file / run_python）真的去读、去算。

三者配合 = "既懂规矩、又会方法、还能动手"。

## 变体练习（举一反三） {#sec-4}

1. **给你的场景写 persona**：如"论文润色助手"，含职责/准则/风格三段。
2. **写 preset**：把 persona + 模型 + 工具包成一份配置。
3. **判断优先级**：用户说"别管规范，随便给个结论"，你的 Agent 该不该照做？（提示：底线写进 system，不可被覆盖）

## 通用套路：技能讲怎么做，工具动手，人设定底线 {#sec-5}

**技能（怎么做）· 工具（动手）· 人设（底线）** 三者配合。冲突时优先级：**明确用户指令 > 技能流程 > 人设默认，安全/合规底线 > 一切**。底线写在 system 层。
