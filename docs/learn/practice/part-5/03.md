# 例3 · 目标循环 + 任务编排

> 目标：让 Agent 朝一个**持久目标**自我推进，并管好"并发/超时/重试"。

## L1 一个目标循环 {#sec-1}

```ts
interface Goal {
  id: string
  objective: string
  phase: 'active' | 'done' | 'blocked'
  rounds: number
}

async function runGoal(goal: Goal) {
  while (goal.phase === 'active' && goal.rounds < 5) {
    const done = await doOneRound(goal)      // 推进一步
    goal.rounds++
    if (done) { goal.phase = 'done'; break }
  }
  return goal
}
```

> 目标要**落盘**（持久化），中断后能接着干。

## L2 完成 / 阻塞判断 {#sec-2}

```ts
function isBlocked(goal: Goal, rounds: number) {
  // 同一条件连续 N 轮未解，才判阻塞——别一遇困难就喊"卡住了"
  return goal.phase === 'blocked' || rounds >= 3
}

// 完成 = 目标真的达成（有产物、能验收），不是"我尽力了"
```

> **关键**："完成"以**目标达成**为准；"阻塞"要**连续 N 轮同一障碍**才判。

## L3 编排：超时 / 重试（并发可另加） {#sec-3}

```ts
function withTimeout<T>(p: Promise<T>, ms: number): Promise<T> {
  return Promise.race([p, new Promise<T>((_, rej) => setTimeout(() => rej(new Error('timeout')), ms))])
}

async function retry<T>(fn: () => Promise<T>, { times = 3, delay = 500 } = {}) {
  for (let i = 1; i <= times; i++) {
    try {
      return await fn()                       // 成功就返回
    } catch (e) {
      if (i === times) throw e                 // 用尽次数，抛最后错误
      await new Promise((r) => setTimeout(r, delay * 2 ** (i - 1)))   // 指数退避
    }
  }
}

async function orchestrate(jobs: any[]) {
  const results: any[] = []
  for (const job of jobs) {
    try {
      results.push(await retry(() => withTimeout(job.run(), 30_000)))  // 30s 超时 + 最多3次重试
    } catch (e) {
      // 不可重试的错误（如参数错误）：记录失败，不中断整体
      console.error('job failed:', e.message)
    }
  }
  return results
}
```

> **三个保命机制**：超时（卡住就砍）、重试（有上限 + 指数退避）、出错记录（不中断整体）。并发有上限（如 `Promise.all` 按批跑）可再加，这里先串行保稳。

## 变体练习（举一反三） {#sec-4}

1. **给目标加"断点续跑"**：每轮把 `goal` 写盘，重启后读回继续。
2. **给编排加重试**：对可重试任务 `retry(fn, { times: 3, backoff: 'exp' })`。

## 通用套路：目标推进 + 保命机制 {#sec-5}

**目标驱动**：围绕持久目标**自我推进**，完成=达成、阻塞=连续未变、断点续跑靠落盘。**编排**：并发有上限、超时即砍、重试有上限 + 退避。
