# 标题规范（Title Spec）

> 目的：解决"标题长短不一 + 四级结构"导致的导航混乱。核心是**分层分工 + 侧栏短名 / 页面全名分离**。遵循此规范，导航自动整齐。

## 一、黄金规则

**侧栏承担"部分 → 章 → 节"三级（可折叠）：部分可折叠、章可折叠、节为同页锚点跳转；页面 H1 用完整标题；小节（H3）不进侧栏。** 标题里的修饰、英文、一句话扩展一律放页面标题，不放侧栏。

## 二、四级标题命名公式

| 层 | 公式 | 侧栏显示（短） | 页面 H1（全） | 是否进侧栏 |
|---|---|---|---|---|
| **部分** | `第〇部分 · <二字功能>` | `第〇部分 · 引子` | `第〇部分 · 引子：先弄懂 Agent 系统是啥` | ✅ 分组（可折叠） |
| **章** | `第N章 <核心概念>` | `第2章 调模型` | `第2章 调模型（LLM Provider）—— 它的脑子` | ✅ 条目（短名，可折叠） |
| **节** | `N.M <短节名>` | `2.1 为什么要有统一入口` | `2.1 为什么要有统一入口` | ✅ 章下（同页锚点跳转） |
| **小节** | `N.M.K <短小节名>` | — | `2.1.1 各模型接口不统一的问题` | ❌ 不进侧栏 |

### 规则要点
1. **侧栏短名只写"第N章 + 核心词"**，删除：英文原词、括号解释、"——它的XXX"一句扩展。
   - 例：`第2章 调模型（LLM Provider）—— 它的脑子` → 短名 `第2章 调模型`；页面 H1 保留完整。
   - 例：`第4章 安全与沙箱（Sandbox / 权限）` → 短名 `第4章 安全与沙箱`。
2. **部分短名控制在"第〇部分 · 二字"**：`引子 / 地基 / 抽象与容器 / 写什么 / 长大 / 编排 / 产品化 / 工程化 / 结课 / 发布后`。
   - 页面 H1 可再加冒号描述（如 `第一部分 · 地基：从一次对话到一次执行`）。
3. **节/小节统一短**，无英文、无描述，只留核心词。**节进侧栏（同页锚点），小节不进侧栏。**
4. **英文原词保留在页面标题**，侧栏短名不含英文，可读性更好、也避免一行太长。
5. **`V0.1 / v0.2 / Agent / LLM`** 等术语在标题可保留，但侧栏短名里尽量精简。

## 三、标题与侧栏的落地（VitePress）

- **侧栏短名**：`config.mts` 的 `sidebar`（`text` 用短名）；侧栏由 `config.mts` **构建时扫描章节 H2 自动生成**（部分→章→节三级，节为锚点）。
- **页面全名**：写在 markdown 的 `# H1`（frontmatter 里可设 `title`）。两者**互不同步**。
- **节锚点**：每个 `## 节` 加显式锚点 `{#sec-k}`（脚本批量加，**忽略代码栅栏**），侧栏节链接指向 `#sec-k`，同页跳转。上下增加 `##` 需保持编号连续。
- **小节（H3）**：不进侧栏，作为正文层级即可。
- **顶部/右侧页内大纲**：已关闭（`outline: false`），节导航由左侧侧栏承担。

## 四、长标题兜底（即使短名仍超长时）

- 侧栏条目统一**截断（`…`）+ 悬停显示全名**（`title` 属性），宽度一致、不换行。
- 当前激活项**高亮 + 左侧细条**，标出"你在哪一页"。
- 部分分组**可折叠**，默认收起已读部分；**章也默认折叠**，点开看节；**当前激活章自动展开**。
- 节条目超长同样**截断 `…` + 悬停全名**。

## 五、交叉引用规范（重要）

因为**每个部分的章号都从"第1章"重新开始**，所以跨部分引用必须带部分号，否则歧义：

| 引用类型 | 正确写法 | 错误写法 |
|---|---|---|
| 跨部分引用章 | `第一部分第3章` | `第3章`（在别的部分里会指向本部分第3章） |
| 同部分引用章 | `第3章` | — |
| 引用节 | `第一部分第1章 1.3.2` | `第1章 1.3.2`（跨部分时） |
| 引用部分 | `第7部分 5.2` | — |
| 章内自引用 | `回看 2.3` | — |

**规则**：**凡是跨部分引用，一律写"第X部分第Y章"**；同部分内可简写"第Y章"。

## 六、快速对照（用第2章做示范）

| 位置 | 显示 |
|---|---|
| 左侧栏（部分） | `▸ 第一部分 · 地基` |
| 左侧栏（章，点开） | `▸ 第2章 调模型` |
| 左侧栏（节，章下） | `2.1 为什么要有统一入口` / `2.2 最小模型调用` / `2.3 关键参数`（同页锚点跳转） |
| 页面 H1 | `# 第2章 调模型（LLM Provider）—— 它的脑子` |
