# Example 1 · Packaging and Release: From Code to Usable

> Goal: others can **install and run** your Agent with one command, instead of "downloading the source and figuring it out yourself."

<!-- 双向导航: 回主线 -->
> 📚 **Start with the main line first**: this exercise corresponds to **[Main Line Part 9](/en/learn/part-9/01)** — read the main-line concepts first, then get hands-on.

## L1 One Entry Point, One Command {#sec-1}

Here is a `package.json` (so users can use it with a single command; note that we place it in a JSON code block, so please do not add comments):

```json
{
  "name": "my-agent",
  "version": "0.3.0",
  "bin": { "my-agent": "./bin/my-agent.js" },
  "scripts": { "start": "node bin/my-agent.js" },
  "dependencies": { "openai": "^4.0.0" }
}
```

```bash
npm install -g my-agent   # 全局安装
my-agent "帮我看个文件"      # 直接当命令用
```

> **Release standard**: install and run out of the box; **dependencies clearly declared**; both `bin` (the command entry) and `scripts.start` (run it) are present.

## L2 Release Artifacts: Include Everything You Need to Run It {#sec-2}

```
my-agent/
├── bin/my-agent.js     # 入口
├── dist/               # 编译出的 JS（若 TS）
├── skills/             # 内置技能
├── README.md           # 怎么装、怎么用
├── package.json        # 依赖与脚本
└── CHANGELOG.md        # 变更记录
```

> **What you ship = everything the user needs to run it.** Don't expect users to read your source code to guess how to install. The README should explain "three steps to run."

## L3 Publish to a Registry / npm {#sec-3}

```bash
npm publish     # 发布到 npm（若开源发布）
# 或发布到 GitHub，README 里写清安装方式
```

> **Pre-release self-check**: `npm pack` to see whether the release artifact has **anything extra, or is missing anything critical**. Make sure **version number + CHANGELOG + tag** are consistent before releasing.

## Variant Exercises (apply it) {#sec-4}

1. **Add a `bin` entry** to the project, so it's usable as a command after `npm install -g`.
2. **Write a "three steps to run"** README.
3. **`npm pack` to check the release artifact**: is anything missing?

## General pattern: one-command install + complete artifact + consistent version {#sec-5}

**A releasable Agent**: ①**has a command entry / one-command run**; ②**ships a complete artifact** (dependencies, skills, README); ③**version number + CHANGELOG + tag are consistent**. **Releasing is "for others to use", not "self-amusement"** — the README is the user's first impression.
