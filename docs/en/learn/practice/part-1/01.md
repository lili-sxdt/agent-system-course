# Example 1 · Minimal Model Call and Context

> Goal: make your first call — send a message to a model and get a reply — and understand context. Go from the minimal (L1) to context in practice (L2), then try a variant exercise.

<!-- 双向导航: 回主线 -->
> 📚 **Start from the main line**: this exercise corresponds to **[Main Line, Part 1](/en/learn/part-1/01)** — read the main-line concepts first, then get hands-on.

## L1 Minimal runnable (just the essentials) {#sec-1}

> Node 18+ ships a global `fetch`, so no installation is needed.

```ts
const KEY = process.env.LLM_API_KEY!

const res = await fetch('https://api.deepseek.com/chat/completions', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json', Authorization: `Bearer ${KEY}` },
  body: JSON.stringify({
    model: 'deepseek-chat',
    messages: [{ role: 'user', content: '用一句话介绍你自己' }],
  }),
})
const data = await res.json()
console.log(data.choices[0].message.content)
```

- **What to grasp**: the request body carries `model` (which model) and `messages` (the context); in the reply, take `choices[0].message`.
- **The key**: `process.env.LLM_API_KEY` reads an environment variable (see Preparation 6).

## L2 In practice: multi-turn context {#sec-2}

> A "conversation" isn't a single message — it's multiple turns of history. Put that history in `messages` in order.

```ts
const messages = [
  { role: 'system', content: '你是简洁的助手。' },
  { role: 'user', content: '我的项目是 Mini-Harness。' },
  { role: 'assistant', content: '好的，记住了。' },
  { role: 'user', content: '项目叫什么？' },     // 这一句靠前面历史才能答
]
const msg = await chat(messages)   // 见下面的 chat()
```

> **Key to coherence**: the history order **must not be shuffled** — `system` always comes first, and tool results must be included too (later).

## L3 A reusable chat() {#sec-3}

```ts
async function chat(messages: any[], opts: { model?: string; temperature?: number } = {}) {
  const res = await fetch(`${process.env.LLM_BASE_URL}/chat/completions`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json', Authorization: `Bearer ${process.env.LLM_API_KEY}` },
    body: JSON.stringify({ model: opts.model ?? 'deepseek-chat', messages, temperature: opts.temperature ?? 0.3 }),
  })
  return (await res.json()).choices[0].message
}
```

## Variant exercises (apply it) {#sec-4}

Tweak it and run it yourself:
1. **Switch the model**: change `model` to another one (e.g. `deepseek-chat` → something else).
2. **Change the temperature**: set `temperature` to `0.9`, then to `0`, and watch how the answer style differs.
3. **Change the context**: remove the middle "assistant" turn and see whether the model still answers "what's the project called?" correctly.

## General pattern: the context formula {#sec-5}

**Context = system (rules) + history (multiple turns) + tool results (later).** Whatever you want the model to "know", put it in `messages`; anything you don't add, it simply won't know.
