# Example 1 · Subagents (Delegating Work and Collecting Results)

> **Goal**: **delegate a large task to a "clone"**, and **collect the result in a structured way**. The key is spawn (a completely fresh context) + persisting the result to disk.

<!-- 双向导航: 回主线 -->
> 📚 **Start with the main line first**: this exercise corresponds to **[Main Line, Part 5](/en/learn/part-5/01)** — read the main-track concepts first, then do the hands-on work.

## L1 Spawn a subagent {#sec-1}

```ts
const result = await spawnSubagent({
  task: '检索近三年马铃薯氮素诊断的高光谱研究，输出 5 篇关键文献',
  schema: {
    papers: [{ title: 'string', doi: 'string', why: 'string' }],
  },
})
console.log(result.papers)
```

> **spawn = a fresh context**: the subagent does not inherit your bias; **auditing / independent evaluation must use spawn**.

## L2 Structured collection + persisting to disk {#sec-2}

```ts
import fs from 'node:fs/promises'   // 结果要落盘，故引入

const result = await spawnSubagent({
  task: '读 data/*.md 并总结成摘要',
  schema: { summary: 'string', fileCount: 'number' },
})

// 1) 结果落盘（即使上下文丢了，成果还在）
await fs.writeFile('subagent-result.json', JSON.stringify(result, null, 2))
// 2) 返回结构化结果 + 产物路径，而非"讲一堆"
```

> **Key point**: the subagent result should be **structured + persisted to disk**. Mark any unpersisted information as **"TODO"** to avoid "said it was done but left no trace".

## L3 Choosing between fork vs spawn {#sec-3}

```ts
// fork：继承父对话（需要共享背景时用）
const r1 = await forkSubagent({ task: '基于我们刚才讨论的，继续补充' })

// spawn：全新（独立、纯净、审计用）
const r2 = await spawnSubagent({ task: '独立评估以下结论是否有证据', schema: { verdict: 'string' } })
```

> Auditing / independent evaluation **must use spawn** — an "audit" that inherits context carries bias, which amounts to self-review.

## Variant exercises (apply it) {#sec-4}

1. **Spawn two subagents in parallel**: one checks "methods", the other checks "data", and wait for both with `Promise.all`.
2. **Give the subagent a schema**: have it return `{ ok, findings }`, and the main Agent integrates based on that.

## General pattern: subagent = independent context + structured persistence {#sec-5}

**Subagents** offer three values: isolation (does not pollute the main context) / parallelism / division of labor. **spawn is fresh, fork inherits** (use spawn for auditing); results should be **structured + persisted to disk**, with unpersisted info marked **TODO**.
