# Example 1 · A Minimal Plugin (Installable and Removable)

> Goal: understand that "a plugin = self-contained + a unified interface + installable and removable." Package one capability into a plugin.

<!-- 双向导航: 回主线 -->
> 📚 **Start with the main line first**: This exercise corresponds to **[Main Line Part 2](/en/learn/part-2/01)** — it is recommended that you read the main-line concepts first, then do the hands-on work.

## L1 Minimal Plugin (Skeleton) {#sec-1}

```ts
import type { Context } from '@deepseek-ai/cordis'

export function myPlugin(ctx: Context) {
  ctx.on('ready', () => {
    console.log('my plugin is ready')
  })
}
```

> A plugin = a function that takes `ctx`. `ctx.on('ready', ...)` means "do something when the system is ready."

## L2 In Practice: Installable and Removable + Cleanup {#sec-2}

```ts
export function myPlugin(ctx: Context) {
  const timer = setInterval(() => { /* do some timed work */ }, 1000)

  ctx.on('dispose', () => {          // clean up on unload
    clearInterval(timer)
    console.log('my plugin cleaned up')
  })
}
```

> **Key point**: when unloading, you **must clean up resources** (timers/connections/listeners); otherwise repeated install/uninstall leaks resources.

## L3 Complete: A "Read-File Plugin" {#sec-3}

```ts
import { readFileTool } from './tools/read-file'

export function fileToolsPlugin(ctx: Context) {
  ctx.tool(readFileTool)     // mount the tool into the system
  ctx.on('ready', () => ctx.something = true)
  ctx.on('dispose', () => console.log('fileTools plugin unmounted'))
}
```

## Variant Exercises (Apply It) {#sec-4}

1. **Write a "log plugin"**: `loggerPlugin` — on `ready`, start a timer that records a heartbeat; on `dispose`, clean it up.
2. **Add configuration to a plugin**: have it read a config item (see Example 3).

## General Pattern: A Plugin Can Be Installed and Removed {#sec-5}

**One capability = one plugin**; a plugin follows a unified interface to be loaded, can be unloaded, and unloads cleanly. Changing one plugin does not affect the others.
