# Example 1 · Session Persistence and Restoration

> Goal: make the Agent "remember after the chat ends" — **persist** the session, then **read it back** next time to keep talking.

<!-- 双向导航: 回主线 -->
> 📚 **Start from the main line**: this exercise corresponds to **[Main Line, Part 4](/en/learn/part-4/01)** — I recommend reading the main-thread concepts first, then doing the exercise.

## L1 Save the session: append to JSONL {#sec-1}

```ts
import fs from 'node:fs/promises'

async function appendMessage(file: string, msg: any) {
  await fs.appendFile(file, JSON.stringify(msg) + '\n')   // 每行一条，追加
}

await appendMessage('session.jsonl', { role: 'user', content: '帮我读 config.json' })
await appendMessage('session.jsonl', { role: 'assistant', content: '好的' })
```

> **JSONL**: one message per line; `appendFile` appends (only adds, never rewrites — safer than rewriting the whole file).

## L2 Restore: read it back and rebuild context {#sec-2}

```ts
import fs from 'node:fs/promises'

async function loadMessages(file: string) {
  const txt = await fs.readFile(file, 'utf8')
  return txt.split('\n').filter(Boolean).map((line) => JSON.parse(line))
}

const messages = await loadMessages('session.jsonl')
console.log('恢复的轮数:', messages.length)
```

> **Three keys to restoring**: ① **Order** must be preserved, ② **Tool results** must be stored (otherwise the model doesn't know what was returned earlier), ③ **Version compatibility** (older formats must still be readable).

## L3 Complete: a reusable conversation store {#sec-3}

```ts
import fs from 'node:fs/promises'

export async function saveSession(id: string, messages: any[]) {
  await fs.writeFile(`session-${id}.jsonl`, messages.map((m) => JSON.stringify(m)).join('\n'))
}
export async function loadSession(id: string): Promise<any[]> {
  try {
    const txt = await fs.readFile(`session-${id}.jsonl`, 'utf8')
    return txt.split('\n').filter(Boolean).map((l) => JSON.parse(l))
  } catch {
    return []
  }
}
```

## Variant exercises (apply it) {#sec-4}

1. **Store tool results**: also save a `tool` result into the JSONL; after restoration the model should know what it has called.
2. **Add a session title**: add a `title` to the session when storing it, reading/modifying/writing with `JSON.parse`/`JSON.stringify`.

## General pattern: session = a storable container for context {#sec-5}

**A session** is the carrier of a conversation: **append** it to disk, and **read it back in order** on restoration (including tool results). "Remembering" comes from "being able to bring everything you need along and read it back".
