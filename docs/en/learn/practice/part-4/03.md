# Example 3 · Memory Compression + Permissions and Approval

> Goal: slim down the memory (compress it), and understand how "permission levels + approval" lets the Agent use things with confidence without causing trouble.

<!-- 双向导航: 回主线 -->

## L1 Compress: summarize a long conversation into one block {#sec-1}

```ts
async function compact(oldMessages: any[], maxTurns = 10) {
  const toSummarize = oldMessages.slice(0, -maxTurns)         // 早期的
  const recent = oldMessages.slice(-maxTurns)                  // 近期的完整保留
  const summary = await chat([
    { role: 'system', content: '把下面的对话压缩成不超过 200 字的关键信息。' },
    { role: 'user', content: toSummarize.map((m) => `${m.role}: ${m.content}`).join('\n') },
  ])
  return [
    { role: 'system', content: `[history summary] ${summary.content}` },
    ...recent,
  ]
}
```

> **Keep in the summary**: the goal, what's done, the todos, and key conclusions — don't just keep pleasantries.

## L2 Permission levels + approval flow {#sec-2}

```ts
const PERMISSIONS = ['read', 'write-workspace', 'full']   // 三级

function canDo(level: string, op: string) {
  if (op === 'read' && level === 'read') return true
  if (op === 'write' && level === 'write-workspace') return true
  return false
}

async function requestApproval(op: string, arg: string) {
  const ok = await askUser(`即将执行 ${op}(${arg})，确认？`)
  return ok
}
```

| Level | What it can do |
|---|---|
| `read` | Read only, no writes |
| `write-workspace` | Read/write within the workspace |
| `full` | Anywhere on the system (requires explicit authorization) |

> **Principle**: by default grant the **minimum sufficient**; anything higher requires **explicit escalation** and **user confirmation** (approval).

## L3 Audit: log sensitive operations {#sec-3}

```ts
import fs from 'node:fs/promises'   // 审计要写文件，故引入

export async function audit(op: string, arg: string, approved: boolean) {
  await fs.appendFile('audit.jsonl', JSON.stringify({
    ts: new Date().toISOString(),
    op, arg, approved,
  }) + '\n')
}
// 示例
await audit('delete_file', 'old.csv', true)
```

> Audit logs must **not contain secrets** and should **only append, never overwrite** (traceable and tamper-resistant).

## Variant exercises (apply it) {#sec-4}

1. **Add a "four elements" check to compression**: after compressing, verify that `goal / done / todos / key conclusions` are all present.
2. **Write an approval + audit**: before deleting a file call `requestApproval`, and after approval log it with `audit`.

## General pattern: slim down + tier + leave a trace {#sec-5}

**Memory**: keep detail close, keep a summary far (compress); **Security**: minimum permission by default + approval for sensitive operations; **Traceability**: audit only appends and never contains secrets.
