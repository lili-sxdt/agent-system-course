# Example 2 · Workspace and Path Safety

> Goal: give the Agent a "safe office" and block any path that tries to slip out (`../../`).

<!-- 双向导航: 回主线 -->
> 📚 **Start from the main line**: this exercise corresponds to **[Main Line, Part 4](/en/learn/part-4/01)** — I recommend reading the main-thread concepts first, then doing the exercise.

## L1 Define the workspace + bounds check {#sec-1}

```ts
import path from 'node:path'

const WORKSPACE = process.env.DSH_PROJECT_DIR ?? process.cwd()

function safePath(workspace: string, userPath: string) {
  const abs = path.resolve(workspace, userPath)   // 解析成绝对路径
  const rel = path.relative(workspace, abs)        // 相对工作区
  if (rel.startsWith('..') || path.isAbsolute(rel)) {
    throw new Error('path out of bounds, access denied')
  }
  return abs
}

console.log(safePath(WORKSPACE, 'data/a.csv'))       // OK
// safePath(WORKSPACE, '../../Windows')              // 越界 → 抛错
```

> **Key point**: judge with `path.resolve` + `path.relative`; **never use string concatenation**.

## L2 Use safe paths inside tools + catch errors {#sec-2}

```ts
import path from 'node:path'

export const readFileTool = defineTool({
  name: 'read_file',
  description: '读取工作区内文件内容。',
  parameters: { type: 'object', properties: { path: { type: 'string' } }, required: ['path'] },
  async handler({ path: userPath }) {
    const workspace = process.env.DSH_PROJECT_DIR ?? '.'
    try {
      const abs = safePath(workspace, userPath)         // 先校验
      const fs = await import('fs/promises')
      return { ok: true, content: await fs.readFile(abs, 'utf8') }
    } catch (e: any) {
      return { ok: false, error: e.message }            // 越界或失败都不崩
    }
  },
})
```

## L3 Design a few safe file tools {#sec-3}

| Tool | Purpose | Note |
|---|---|---|
| `read_file` | Read | Paginate/truncate large files |
| `write_file` | Write | **Atomic write** (temp file + replace) |
| `list_files` | List directory | Limit depth, skip huge directories |
| `search` | Search content | Limit scope |
| `edit` | Targeted replace | Exact match |

## Variant exercises (apply it) {#sec-4}

1. **Write a `write_file`**: also start with `safePath`, use **atomic write** (write `x.tmp` first, then rename).
2. **List the directory**: in `list_files`, validate each file is inside the workspace first; skip anything out of bounds.

## General pattern: settle the workspace first, then talk files {#sec-5}

**Workspace = operating area + security boundary**. Validate file operations with `safePath` first; writing should be **atomic**, large files **truncated**. **Reject outright** when out of bounds — don't "do your best".
