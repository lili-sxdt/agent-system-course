# Example 2 · Define a Tool + Tests

> **Goal**: define a tool with `defineTool`, then write tests for it (normal + error). The core is N-D-P-H + a unified return shape + vitest.

<!-- 双向导航: 回主线 -->
> 📚 **Ground yourself with the main line first**: this exercise maps to **[Main line · Part 3](/en/learn/part-3/01)** — read the main-line concepts first, then build it hands-on.

## L1 A minimal tool (N-D-P-H) {#sec-1}

```ts
import { defineTool } from './tool'

export const listFilesTool = defineTool({
  name: 'list_files',
  description: '列出指定目录下的文件名。需要知道某文件夹有哪些文件时使用。',
  parameters: {
    type: 'object',
    properties: { dir: { type: 'string', description: '目录路径' } },
    required: ['dir'],
  },
  async handler({ dir }) {
    const fs = await import('fs/promises')
    try {
      return { ok: true, files: await fs.readdir(dir) }
    } catch (e: any) {
      return { ok: false, error: e.message }
    }
  },
})
```

## L2 Standard return shape + description {#sec-2}

> **Unified return shape** `{ ok, ... }`: on success it carries data, on failure it carries `error` — **don't throw an exception and crash**. **Write the description to say "when to use it"**, so the model invokes it correctly.

```ts
export const countWordsTool = defineTool({
  name: 'count_words',
  description: '统计一段文字的单词数。当用户要求"数一下多少词"时使用。',
  parameters: { type: 'object', properties: { text: { type: 'string' } }, required: ['text'] },
  async handler({ text }) {
    if (typeof text !== 'string') return { ok: false, error: '需要字符串 text' }
    return { ok: true, count: text.trim().split(/\s+/).filter(Boolean).length }
  },
})
```

## L3 Write tests for the tool (vitest) {#sec-3}

```ts
import { expect, test } from 'vitest'

test('正常：列出目录', async () => {
  const r = await listFilesTool.handler({ dir: '.' })
  expect(r.ok).toBe(true)
  expect(Array.isArray(r.files)).toBe(true)
})

test('不存在目录：返回错误而不抛', async () => {
  const r = await listFilesTool.handler({ dir: '/no-such-dir-' + Date.now() })
  expect(r.ok).toBe(false)
  expect(typeof r.error).toBe('string')
})
```

## Variant exercises (apply it) {#sec-4}

Using N-D-P-H + a unified return shape + vitest, write:
1. **read_file**: read file contents (error case: file doesn't exist).
2. **sum_numbers**: sum a numeric array (error case: argument isn't an array).

## General pattern: N-D-P-H + unified return shape {#sec-5}

**N**ame · **D**escription (when to use it) · **P**arameters · **H**andler. Return shape unified to `{ ok, ... }`; on failure return `error` instead of throwing; use vitest to test both the normal and error paths.
