# Chapter 5: Setting Up Your Environment

> Time to get hands-on. This chapter sets up your development environment and runs a minimal agent program — **hello-agent**. This is your first "buildable block."

We use **Node.js + TypeScript** (the same stack as DSH, so what you learn maps directly onto the DSH source).

## 5.1 Install Node.js and npm {#sec-1}

**In plain terms**: Node.js is a runtime that lets JavaScript run on your computer; npm is its "software store" for installing third-party libraries. Install both and you can run JS/TS projects.

**Steps**:
1. Download the LTS version from [nodejs.org](https://nodejs.org/) and follow the installer.
2. Open a terminal (PowerShell / CMD on Windows) and verify:

```bash
node -v     # shows a version, e.g. v22.x
npm -v      # shows a version, e.g. 10.x
```

**Technical**: Node.js is a JavaScript runtime built on the V8 engine, providing filesystem, network, and process capabilities (which we will use). npm (Node Package Manager) handles dependency installation and version management.

## 5.2 Initialize a TypeScript project {#sec-2}

**In plain terms**: TypeScript is "JavaScript with types," which catches errors earlier. We now create a project you can write and run.

Run these in the terminal (in the folder where you want the project):

```bash
mkdir my-agent && cd my-agent
npm init -y                       # generates package.json
npm install -D typescript @types/node
npx tsc --init                    # generates tsconfig.json
```

**Technical**:
- `npm init -y` generates `package.json` (project manifest).
- `npm install -D` installs dev dependencies: `typescript` (the TS compiler), `@types/node` (Node's type declarations).
- `npx tsc --init` generates `tsconfig.json` (TS compiler config).

## 5.3 Run hello-agent (a minimal agent program) {#sec-3}

**In plain terms**: Before anything complex, we just make the program "call a large model once" — the minimal seed of an agent: give the model a sentence, get a sentence back.

Write `hello-agent.ts` (illustrative; uses an OpenAI-compatible interface; **use your actual model/service**):

```ts
// hello-agent.ts — minimal: send one message, get a reply
// Node 18+ ships a global fetch, so no extra install is needed (use node-fetch on older versions)

const MODEL = 'deepseek-chat'            // use your actual model name
const API = 'https://api.deepseek.com/chat/completions' // use your actual service URL
const KEY = process.env.LLM_API_KEY!     // keep the key in an env var — never hardcode it! (see note)

async function main() {
  const res = await fetch(API, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${KEY}`,
    },
    body: JSON.stringify({
      model: MODEL,
      messages: [
        { role: 'system', content: 'You are a concise assistant.' },
        { role: 'user', content: 'Introduce yourself in one sentence.' },
      ],
    }),
  })
  const data = await res.json()
  console.log(data.choices?.[0]?.message?.content ?? data)
}

main()
```

Run it:

```bash
# set the key first (Windows / PowerShell)
$env:LLM_API_KEY = "your-key"
# then run
npx tsx hello-agent.ts
```

> **Important (security)**: keep the **API key in an environment variable**, never hardcode it or commit it to Git. Part 4 / Part 7 cover key and security management in depth.

**Technical**: this pipeline already contains an agent's "first step" — **handing the context (system + user messages) to the model.** A true agent adds "tools + loop" later (Part 1 §2–§5).

**Try it**: change `content` to a request that needs "looking something up / arithmetic," and see whether the model answers directly or says "it can't" — this verifies the "ability boundary" from Chapter 1.
