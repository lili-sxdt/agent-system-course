# Prep 2 · Arrays and Objects

> An array is a list; an object is a set of "key: value" pairs.

## 1 Array {#sec-1}

```ts
const nums = [1, 2, 3]
nums.push(4)                              // [1,2,3,4]
const d = nums.map(n => n * 2)            // [2,4,6,8]
const evens = nums.filter(n => n % 2 === 0) // [2,4]
const total = nums.reduce((a, b) => a + b, 0) // 10
console.log(nums.length)   // 4
```

## 2 Object {#sec-2}

```ts
const user = { name: 'Alice', age: 30 }
console.log(user.name)   // Alice
user.age = 31
```

## 3 Destructuring {#sec-3}

```ts
const { name, age } = user       // name='Alice', age=30
const [first, second] = [10, 20]
```

## 4 Spread {#sec-4}

```ts
const b = [...[1, 2], 3]                  // [1,2,3]
const o2 = { ...user, age: 31 }           // merge
```

## 5 Map a field out of a list (common) {#sec-5}

```ts
const files = [{ name: 'a.md' }, { name: 'b.md' }]
const names = files.map(f => f.name)   // ['a.md','b.md']
```
