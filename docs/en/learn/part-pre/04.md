# Prep 4 · Classes and Objects

> A class is a template; an object is an instance.

## 1 A simple class {#sec-1}

```ts
class Dog {
  name: string
  constructor(name: string) { this.name = name }
  bark() { return `${this.name} says woof` }
}
const d = new Dog('Rex')
console.log(d.bark())   // Rex says woof
```

## 2 Inheritance (simple) {#sec-2}

```ts
class Puppy extends Dog {
  bark() { return `${this.name} says yip` }
}
```

## 3 What you'll mostly see (interface + object) {#sec-3}

```ts
interface ToolDef {
  name: string
  handler(args: any): Promise<{ ok: boolean }>
}
const t: ToolDef = { name: 'read_file', async handler() { return { ok: true } } }
```

> **You'll use this later**: `interface` (with object literals) is how you define "what shape something is" throughout the course — `ToolDef`, `Session`, `Message`, `SkillDef` are all interfaces; when you write tools, skills, and personas in Parts 2–3 you're defining these interfaces.
