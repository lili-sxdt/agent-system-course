# Prep 3 · Functions and Control Flow

> A function is "a reusable chunk of logic"; control flow is "branches and loops." Agent code is built on `async function` + `if/for`.

## 1 Functions {#sec-1}

```ts
function add(a, b) { return a + b }
const mul = (a, b) => a * b     // arrow function
console.log(add(2, 3), mul(2, 3))  // 5 6
```

> **You'll use this later**: `async function` + `if/for` is the skeleton of the Agent loop — Part 1's "think → call tool → see result → think again" is a `for` around an `if`; arrow functions `x => ...` show up constantly in `map/filter` and `defineTool` callbacks.

## 2 Arrow that omits return {#sec-2}

```ts
const double = x => x * 2
```

## 3 if / else {#sec-3}

```ts
const score = 75
if (score >= 60) { console.log('pass') } else { console.log('fail') }
```

## 4 for..of {#sec-4}

```ts
for (const n of [1, 2, 3]) { console.log(n) }   // 1 2 3
```

## 5 Combine {#sec-5}

```ts
function countEven(list: number[]) {
  let c = 0
  for (const n of list) if (n % 2 === 0) c++
  return c
}
console.log(countEven([1, 2, 3, 4]))   // 2
```
