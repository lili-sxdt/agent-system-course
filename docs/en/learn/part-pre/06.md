# Prep 6 · Node and Async

## 1 Modules

```ts
import fs from 'node:fs/promises'
import path from 'node:path'
export function double(x: number) { return x * 2 }
```

## 2 async / await

```ts
async function main() {
  const text = await fs.readFile('a.txt', 'utf8')
  console.log(text)
}
main()
```

## 3 Common capabilities

```ts
import fs from 'node:fs/promises'
import path from 'node:path'
import os from 'node:os'

const text = await fs.readFile('config.json', 'utf8')
const p = path.join(os.tmpdir(), 'x')
const key = process.env.LLM_API_KEY
const data = JSON.parse(text)
```

> Security: read keys from `process.env`, never hardcode or commit.

## 4 A minimal runnable example

```ts
import fs from 'node:fs/promises'
async function main() {
  const key = process.env.LLM_API_KEY
  const cfg = JSON.parse(await fs.readFile('config.json', 'utf8'))
  console.log('key set:', Boolean(key), '| port:', cfg.port)
}
main()
```
