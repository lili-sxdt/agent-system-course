# Prep 1 · Variables and Types

> Variables store values; types describe what they hold.

## 1 Declare: const / let {#sec-1}

```ts
const name = 'Alice'   // constant: cannot change (use by default)
let count = 0          // variable: can change
count = count + 1
```

## 2 Basic types {#sec-2}

| JS/TS | holds | example |
|---|---|---|
| `string` | text | `'hi'` |
| `number` | number | `42`, `3.14` |
| `boolean` | true/false | `true`, `false` |
| `null` | explicit empty | `null` |
| `undefined` | not assigned | `undefined` |

## 3 Type annotations (TS) {#sec-3}

```ts
const age: number = 30
const name: string = 'Alice'
let ok: boolean = true
```

## 4 Operators example {#sec-4}

```ts
const x = 5, y = 2
console.log(x + y)   // 7
console.log(x / y)   // 2.5
console.log(x % y)   // 1
console.log(x === 5)   // true
console.log(x === '5') // false (number !== string)
```

## 5 Template literals {#sec-5}

```ts
console.log(`${name} is ${age}`)   // Alice is 30
```
> Use backticks + `${}`.
