# Prep 5 · TypeScript Types

## 1 Annotations {#sec-1}

```ts
const name: string = 'Alice'
function add(a: number, b: number): number { return a + b }
```

## 2 interface {#sec-2}

```ts
interface Message {
  role: 'system' | 'user' | 'assistant'
  content?: string          // ? = optional
}
const m: Message = { role: 'user', content: 'hi' }
```

## 3 Generic `<T>` {#sec-3}

```ts
function first<T>(arr: T[]): T { return arr[0] }
const n: number = first([1, 2])
```

## 4 Assertion as {#sec-4}

```ts
const data = JSON.parse(text) as { ok: boolean; error?: string }
```

## 5 Reading course code {#sec-5}

```ts
const messages: Message[] = [ ... ]
const r = await chat(messages) as { content: string }
```

> **You'll use this later**: this is almost the exact "shape" of the code in Parts 1–3 — `messages: Message[]` (the conversation array), `Promise<{ ok: boolean }>` (a tool return value), and `as {...}` (parsing a model reply). Get comfortable with these and you won't get stuck reading the course code.
