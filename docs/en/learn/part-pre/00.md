# Prep 0 · Environment Setup

> Get "it runs" out of the way first. Install Node, make a TS project, and run your first `console.log`.

## 1 Install Node {#sec-1}

> JS/TS runs on **Node** (like Python on an interpreter). Node ships with `npm` (package installer).

1. Download the **LTS** from <https://nodejs.org/> and install;
2. Open a terminal (PowerShell / CMD on Windows) and verify:
```bash
node -v     # e.g. v22.x
npm -v      # e.g. 10.x
```

## 2 Make a TS project {#sec-2}

```bash
mkdir my-agent && cd my-agent
npm init -y                          # makes package.json
npm install -D typescript @types/node
npx tsc --init                       # makes tsconfig.json
```

## 3 Run a .ts {#sec-3}

> Use **tsx** (Node cannot run TS directly).

```bash
npm install -D tsx
tsx hello.ts    # uses hello.ts below
```

```ts
const a = 2
const b = 3
console.log(a + b)               // 5
console.log("hello, " + (1 + 2)) // hello, 3
```

> **Note**: `string + number` in JS is **concatenation** (`"hello, " + 1 + 2` → `"hello, 12"`); to do arithmetic add parentheses: `+ (1 + 2)`.

## 4 Common operators {#sec-4}

| Op | JS | Example | Result |
|---|---|---|---|
| add/sub/mul/div | `+ - * /` | `7 / 2` | `3.5` |
| modulo | `%` | `7 % 2` | `1` |
| equal/not | `===` `!==` | `2 === 2` | `true` |
| greater/less | `>` `<` | `3 > 2` | `true` |
| and/or/not | `&&` `\|\|` `!` | `true && false` | `false` |

> **Key**: use `===` (strict). Logic uses `&&` `\|\|` `!`.

## 5 Read a file {#sec-5}

```ts
import fs from 'node:fs/promises'
const text = await fs.readFile('hello.ts', 'utf8')
console.log(text.length)
```

## Checklist {#sec-6}
- [ ] `node -v` / `npm -v` print versions;
- [ ] `package.json` + `tsconfig.json` exist;
- [ ] `tsx` runs `hello.ts` and shows output;
- [ ] can use `+ - * / %`, `===`, `&&`, `!`;
- [ ] can read a file.

**Follow-up**: in JS, `7 / 2` is `3.5` (like Python `/`). To get an integer use `Math.floor`.
