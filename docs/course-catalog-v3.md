# 课程设计 · 完整目录 v3

> **课程**：从零到能自己编写一个 DeepSeek Harness 同类 Agent 系统，并发布维护到 v0.2
> **语言要求**：通俗易懂 + 专业规范（以"大白话引入 → 最小可跑示例 → 专业定义/规范 → 动手练 → 验收"五件套为目标；纯概念章以"最小可观察示例"替代"最小可跑示例"）
> **技术底座**：Node + TypeScript（与 DSH 同栈，概念一一对应，学完可直接映射到 DSH 源码）

## 标注约定（每条内容都标归属）

- **【课】** ＝ 课程负责：可教的方法论/知识，写入课程即可覆盖。
- **【做】** ＝ 发布动作 / 外部验证：需你亲自做的经验/实践，课程只能给方法，手感靠真实发布一轮获得。
- **【课+做】** ＝ 课程给方法论，但需你真做验证才完整。

## 课程负责 vs 你亲自做的分布

- **【课】**：覆盖"学到知识、会用、能写"的绝大部分（第〇~八部分主体 + 九部分的知识分块）。
- **【做】**：真机装、真发布、真收反馈、真踩坑、真回滚——这些只能靠你做，课程只给方法。
- **【课+做】**：课程给完整方法论，但要你实际操作验证才算真正掌握。

> **一句话**：课程能把"知识 + 方法"教到接近 100%，把"能发布到 v0.2 的动作与手感"只能给到方法层——剩下那层（真实地"发一版、被人用、出问题、修掉、再发 v0.2"）必须由你亲自完成一个版本周期。
